# OrderKoro brand

Name: **OrderKoro** (one word, capital O and K). Never "Order Koro", "OrderPage" or "Orderkoro".

Mark: green "ok" with an orange dot, traced from the approved logo.

| Token | Value | Use |
|---|---|---|
| Green | `#0A694B` | Mark, wordmark, primary buttons on OrderKoro pages |
| Orange | `#F78E10` | The dot only, small accents |
| Cream | `#F5F4F0` | Icon tile and share-image background |
| Ink | `#1B1B18` | Body text |
| Muted | `#5C5A52` | Secondary text |

Rules
- Wordmark is live text in Anek Bangla 800 (not an image), colour green, next to the mark.
- Light backgrounds: `logo-mark.svg`. Dark or green backgrounds: `logo-mark-on-dark.svg` (white "ok", orange dot). Never recolour with CSS filters.
- Single colour needed (stamp, watermark): `logo-mark-mono-white.svg`.
- Clear space around the mark: at least the height of the dot. Minimum height 20 px.
- Do not stretch, outline, add shadows, or put the mark on busy photos.
- This is OrderKoro's logo only. Seller logos are separate and never replaced by it.
